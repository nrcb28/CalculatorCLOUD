# Arquitectura v0.1

La interfaz React vive en `src/main.tsx`; el motor puro decimal y los modelos en `src/engine.ts`. Tailwind 4 se procesa mediante Vite. Recharts representa proyecciones con la tarifa seleccionada.

El núcleo Rust se separa en `src-tauri/src/provider.rs` (HTTPS y caché temporal) y `src-tauri/src/validation.rs` (esquema de presupuestos). Puede probarse con `--no-default-features --lib` sin GTK. Rust en `src-tauri/src/main.rs` ofrece comandos acotados: consultar Azure, guardar y recuperar snapshots. SQLite se almacena en el directorio de datos de la aplicación por usuario. Las consultas SQL están parametrizadas. No se permite HTTP arbitrario desde el frontend. El backend valida filtros y restringe la paginación al endpoint HTTPS oficial; desactiva redirecciones. La caché es por SKU/región/moneda, con caducidad de 1–720 horas y recuperación sin conexión. Una tarifa caducada se señala en interfaz. Los presupuestos almacenan el precio consultado y no se actualizan silenciosamente.

La primera versión calcula solo computación Linux de pago por uso. Se excluyen candidatos Windows, Spot y Low Priority. No selecciona automáticamente la tarifa más barata. El usuario revisa el producto y el SKU. No infiere rendimiento ni equivalencia técnica a partir del nombre del SKU. Almacenamiento y red se registran como solicitudes sin coste calculado. Los importes son subtotales, nunca un presupuesto completo.

Extensión: extraer `providers/azure.rs`, implementar el mismo contrato para AWS y GCP, normalizar una estructura `PriceComponent` con fuente, SKU, región, moneda, unidad, vigencia, tramos y alcance. Añadir inventario técnico verificado antes de recomendar equivalencias. La selección de proveedor necesita cobertura completa y moneda común verificable.

Seguridad: sin secretos persistidos; el panel de acceso acepta una API key de GCP para una comprobación puntual y la envía en cabecera HTTPS, HTTPS con validación TLS, CSP restrictiva, permisos mínimos Tauri, sin shell, sin lectura arbitraria del sistema. El CSV neutraliza prefijos de fórmulas. Importaciones JSON limitadas a 5 MB. Las respuestas HTTP se limitan a 20 MB durante la lectura, aunque no exista Content-Length. Se valida el esquema nativo de presupuestos y la coincidencia entre identificador SQL y JSON. El conector tiene un plazo total de 90 segundos.
